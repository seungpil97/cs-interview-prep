# CS Interview Prep

코딩테스트 풀이와 CS 개념을 함께 기록하는 저장소입니다.

단순히 정답 코드만 작성하는 것이 아니라,  
다음 내용을 함께 정리하는 것을 목표로 합니다.

- 문제 풀이 코드 (Java)
- 풀이 아이디어 및 접근 과정
- 시간복잡도 / 공간복잡도 분석
- OS / 네트워크 / DB / Java / Spring CS 개념 정리
- 면접 예상 질문과 답변

## 목표
- 코딩테스트 기초 체력 만들기 (프로그래머스 Level 3 / 백준 골드)
- CS 개념을 Java와 연결해서 이해하기
- 면접에서 말로 설명할 수 있는 수준까지 정리

## 진행 방식
- 주 5일, 하루 1~1.5시간
- 코딩테스트 1문제 / CS 개념 1주제 병행
- 주차별 docs로 학습 기록 정리
